\begin{itemize}
    \item 無向圖是歐拉圖：
    \begin{itemize}
        \item 非零度頂點是連通的
        \item 頂點的度數都是偶數
    \end{itemize}
    \item 無向圖是半歐拉圖(有路沒有環)：
    \begin{itemize}
        \item 非零度頂點是連通的
        \item 恰有 2 個奇度頂點
    \end{itemize}
    \item 有向圖是歐拉圖：
    \begin{itemize}
        \item 非零度頂點是強連通的
        \item 每個頂點的入度和出度相等
    \end{itemize}
    \item 有向圖是半歐拉圖(有路沒有環)：
    \begin{itemize}
        \item 非零度頂點是弱連通的
        \item 至多一個頂點的出度與入度之差為 1
        \item 至多一個頂點的入度與出度之差為 1
        \item 其他頂點的入度和出度相等
    \end{itemize}
\end{itemize}
